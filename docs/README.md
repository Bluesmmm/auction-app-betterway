## 当前基线

- 产品形态：面向小学 3-4 年级儿童的微信小程序积分拍卖社区。
- 核心原则：孩子参与提交、求购、出价；家长监护确认；活动管理员审核治理；平台管理员兜底复核。
- 交易规则：不接微信支付，不记录人民币补差价；系统内只处理积分。
- 积分规则：每个孩子一个全局积分账户，积分不可充值、提现或系统外转让。
- 内容边界：所有拍品、求购、响应、图片和文本必须经过 AI 风险识别与人工审核后展示。
- 生产边界：默认拦截自买自卖、同家庭互拍、内容修改绕审、邀请码超用和注销未收口。
- 治理收口：暂停发布、出价、结算、社区或分类时，必须明确活跃拍卖、冻结积分和待确认交易处理方式。
- 时间边界：所有拍卖、撤销、确认和超时裁决只认服务端/数据库时间，客户端时间只用于展示。
- 安全边界：未授权搜索、未审核文件访问、日志/导出泄露、通知乱序误导和管理员误操作必须作为上线前阻断项。
- 账号边界：家长、管理员和机构账号的敏感操作必须二次验证、可撤销、可审计；管理员高危操作默认双人或平台复核。
- 生命周期边界：备份恢复、数据库迁移、灰度发布、注销删除、第三方供应商和导出文件都必须纳入儿童信息保护范围。
- 技术基线：微信小程序原生 + NestJS 模块化单体 + PostgreSQL + Redis + BullMQ + Web 管理后台。

## 文档状态

这些文档是产品与技术设计基线，不是最终法务意见。涉及儿童个人信息、未成年人保护、网络交易平台责任和用户协议的内容，上线前需要法务复核。
